# 账套工作工具领域术语

本词汇表记录账套工作工具中用于交流导账需求的业务术语。

## Language

**来源软件**：
生成待导入原始表格的财务软件及其适用版本。它与接收导账结果的目标产品不同。

**科目余额表导账**：
以来源软件导出的科目余额表等原始表格为输入，将账务数据迁移到柠檬云的业务流程。
_Avoid_：导账包上传（后者的输入是已生成的账套数据压缩包）

**会计准则**：
目标账套采用的会计核算规范。

**纳税人类型**：
目标账套对应企业的纳税人身份类别。

**目标账套**：
本次科目余额表导账在当前登录套餐下新建的企业专业版账套。页面中的账套名称是该新账套的名称。

**原始表格**：
来源软件导出的余额表、科目表、凭证表等账务附件。一次导账可以包含多类表格，其必填与可选范围由来源软件的导账要求决定。

**申请启用年月**：
用户为新账套选择的启用月份，默认当前年月。存在更早的凭证月份时，最终启用年月会提前至该凭证月份。

**最终启用年月**：
服务端用于创建账套的实际启用月份，取申请启用年月和最早凭证月份的较早者；没有有效凭证月份时使用申请启用年月。

**导入零余额科目**：
将余额表中金额为零或空的行纳入导账的选项，默认关闭。

**停止查询**：
停止等待和查询导账结果的操作，不取消服务端已经受理的导账任务。
_Avoid_：取消导账
