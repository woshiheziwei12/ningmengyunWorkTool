# 科目余额表导账验证

`SubjectBalanceImportTests.pro` 使用 Qt Test 和仅监听本机环回地址的模拟 HTTP 服务。测试不使用真实 Token，不调用真实导账服务，不创建云端账套；历史写入临时文件。

覆盖内容：

- 70 个来源软件的配置完整性、必填附件、亿企 TXT 科目的条件校验及文件格式检查。
- multipart 文件内容、UTF-8 文件名和辅助类别、中文及特殊字符账套名称编码、专业版参数、鉴权和零余额选项。
- 受理后自动查询，成功/部分导入/失败/处理中、未知状态、缺失或错误任务编号、认证失败及无法识别的响应。
- 禁止重复提交；停止查询后等待超过 10 秒，确认轮询定时器停止；继续查询及提交结果不确定时不自动重发。
- 页面切换软件清空附件；历史记录保留提交域名，按用户及套餐隔离，不存储凭据。

在独立构建目录中使用 Qt 5.12 `qmake` 生成后运行 `nmake`。MSVC 构建前后必须遵守根规则中的进程记录、PDB 服务清理和原程序 EXE/PDB 哈希保护；不要在正常产物或中间目录中执行验证构建。

主窗口导航和截图由 `WorkspaceUiSmoke.cpp` 验证，包含功能 ID 24、70 个软件加占位选项、默认不导入零余额、返回分类和 800×480 滚动布局。运行测试可设置 `BALANCE_TEST_SCREENSHOTS` 指向隔离目录保存独立页面截图。

本次验证产物位于 `.diagnostics/balance-import/`：`test-results.txt` 为接口测试结果，`Smoke/tests-offline.log` 为主窗口验证结果，各构建目录保存过程日志、进程快照、原 EXE/PDB 前后哈希。

服务端静态规则核对不等同各软件真实样本导账。亿企独立凭证、易代账/芸豆凭证 ZIP 的当前解析限制见 `docs/subject-balance-import-catalog.md`，页面会显示对应提示。

## 登录与默认值扩展验证

新增测试覆盖密码登录唯一入口、正式/测试环境切换、分环境记住密码、取消旧请求、登录全链路域名一致与未勾选时不保存密码；全部使用环回模拟服务和临时配置。

附件匹配覆盖同账套唯一匹配、不同账套排除、多个候选、已选附件保留、临时文件/子目录/格式排除、默认账套名称及保留手动名称。启用年月仅验证当前月份默认值，不解析 Excel 内容。

扩展验证日志与截图目录：`.diagnostics/login-import-polish/`。
