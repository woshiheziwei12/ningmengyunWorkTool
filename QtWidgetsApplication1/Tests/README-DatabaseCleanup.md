# 非系统数据库清理验证

入口：文件处理 → 选择删除数据库。下拉框自动列出本地默认/命名实例（Windows 身份验证），并保留 211 实例（本机配置的 SQL 登录，见 readme.md）。进入页面或切换实例不发起连接，点击读取后展示带复选框的清单，默认全不选，可逐项勾选或通过全选按钮选择全部；确认框仅包含勾选的数据库。

`DatabaseCleanerTests.cpp` 通过内存 Session 验证清理流程，不连接真实 SQL Server：

- 系统库名称、ID、Resource、自定义分发库不可删除。
- 实例或目标改变、所选数据库同名重建或消失、清单注入系统库时拒绝旧确认。新增未选数据库始终保留。
- 仅删除勾选的数据库，空选择不会退化为全部删除；勾选快照可保留源库，源库有未勾选快照时不隐式删除快照。已选快照先于源库删除；失败继续处理其他库；停止后不再执行后续删除。
- 最终复核失败不能报全部完成；执行中新增的库保留并计入剩余数量。
- 特殊数据库名中的单引号、右方括号及 `%1` 正确转义；批次再次核对身份并在删除失败后恢复访问模式。

`WorkspaceUiSmoke.cpp` 同时验证 22 个入口、18 条本地路由、本地实例及 211 选项、无凭据输入框、初始删除禁用、切换清单失效及小窗口滚动。`runDatabaseCleanupWidgetTests` 使用内存清单覆盖逐项选择、全选、取消全选、已选数量、确认框只列所选项、取消不启动删除、执行期间锁定选择及刷新清除勾选。

隔离构建时通过 `ForceImportBeforeCppTargets` 导入 `Tests/WorkspaceUiSmoke.targets`，设置 `TargetName=WorkspaceUiSmoke`。必须隔离 OutDir、IntDir、编译 PDB/PCH、QtIntDir、TLogLocation、清理日志与 Qt 生成文件，并遵守进程归属记录和原 EXE/PDB 哈希复核规则。测试运行参数为截图输出目录，APPDATA、LOCALAPPDATA 使用独立路径。

本机验证使用 MSVC v143、Qt 5.12.0、Windows SDK 10.0.22000.0；验证构建设置 `_SILENCE_STDEXT_ARR_ITERS_DEPRECATION_WARNING` 以兼容 Qt 5.12 的旧 STL 迭代器，保留其他编译诊断。MSVC v141 会使现有 QStringLiteral 中文导航文字乱码，不作为本功能的最终验证版本。

2026-09-17 验证结果：正式入口隔离构建通过；离线流程、界面及打包依赖测试通过；导出的 SQL 样本经本机 Microsoft ScriptDom 的 SQL Server 2008 解析器校验，外层批次与两个动态删除批次均无语法错误。未执行真实数据库删除，未验证远程连接或真实 DROP 的运行结果。原启动 EXE/PDB 的存在状态和 SHA-256 均保持不变。

2026-09-20 多实例验证：正式 Release 入口隔离构建、全工作区离线界面回归、恢复连接地址/认证切换及删除清单实例绑定测试通过。32 位程序发现默认实例与 `SQL2008R2`；命名实例的只读连接、服务器目录与数据库枚举通过（SQL Server 10.50.4000.0）。默认实例服务处于 Stopped，连接检查返回超时；未启动服务，未执行真实恢复或删除。构建期间原 EXE/PDB 存在状态及 SHA-256 复核一致。
